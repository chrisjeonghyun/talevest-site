제1조 목적 및 적용 범위

운영자 법적 명칭: 주식회사 스튜디오폴리
대표자: 신정현
주소: 서울 영등포구 여의서로 43, 614-A85호(여의도동, 한서리버파크)

위 운영자(이하 “운영자”)는 Finpedia / Talevest Content Operations에 관하여 소유 또는 적법한 관리 권한을 보유한 YouTube 채널의 콘텐츠 운영을 지원하는 내부 API 클라이언트(이하 “클라이언트”)에 본 방침을 적용한다. 뉴스레터 구독 서비스의 개인정보 처리는 별도의 고지에 따른다. 본 클라이언트는 YouTube API Services를 이용한다. Google의 정보 처리에는 Google 개인정보처리방침이 적용된다. 클라이언트 기능의 이용 전 본 방침에 대한 동의를 받아야 한다.

제2조 처리 항목 및 목적

운영자는 부여받은 접근 권한의 범위에서 다음 정보를 처리한다.

  1. 채널 식별자 및 영상 식별자, 제목·설명·태그·재생목록·섬네일 정보, 공개 상태, 예약 공개 시각, 업로드·처리 상태: 승인된 콘텐츠의 게시·정정·예약 관리 및 결과 검증.
  2. 소유 채널 영상의 댓글 식별자, 댓글 본문, 공개 작성자 표시정보, 게시·수정 시각 및 운영자가 승인한 답글: 댓글 운영 및 처리 결과 확인. 댓글에 포함된 개인정보는 해당 목적에 필요한 최소 범위에서 처리한다.
  3. 조회수·시청시간·평균 시청지속시간·구독자 증감·유입경로 등 채널 또는 영상 단위 분석 지표: 콘텐츠 성과 확인. 개별 시청자의 신원을 식별하는 자료를 요청하지 않는다.
  4. OAuth 접근·갱신 토큰, 부여된 권한 범위 및 유효성 정보: 승인된 API 접근. Google 계정 비밀번호는 수집하지 않는다.
  5. 운영 승인, API 실행 결과, 장애·검증 기록, 문의 발신 주소 및 요청 내용: 오게시 방지, 사고 대응 및 권리 행사 처리.

제3조 보유 기간

  1. 영상 메타데이터, 댓글 등 API 원자료 및 그 사본은 수집·갱신일부터 30일 이내에 갱신하거나 삭제한다. 오래된 스냅샷을 보유한 채 최신 사본만 갱신하는 것은 기존 사본의 갱신으로 보지 않는다.
  2. 소유 채널의 적법한 승인에 따라 취득한 분석·통계 자료는 비교 분석에 필요한 범위에서 최대 13개월 보유한다. 이 경우 적어도 30일마다 접근 권한 및 해당 영상의 존속 여부를 확인하며, 확인이 불가능한 자료는 계속 보유하지 않는다. 승인 없이 취득한 공개 통계 자료는 이 장기 보유 대상에서 제외한다.
  3. OAuth 토큰은 승인된 기능의 운영에 필요한 기간에만 보유한다. 승인 철회 시 재사용을 중단한다.
  4. 삭제 요청 및 클라이언트를 통한 동의 철회가 접수된 경우 지체 없이 처리하고 늦어도 7일 이내 해당 승인에 따라 저장한 데이터를 삭제한다. Google 계정에서 직접 철회한 경우 정기 확인으로 이를 탐지하여 지체 없이 삭제하되 철회일부터 30일을 넘기지 않는다.
  5. 문의 원문은 처리 종료 후 30일 이내 삭제한다. 삭제 이행 증거는 원문, 토큰, 채널·영상 식별자 등 재식별 정보를 제외한 처리일·항목수·결과만 1년 보유한다. 법령에 의한 별도 보관이 필요한 경우에는 해당 법적 근거와 범위를 별도로 고지한다.
  6. 위 보유 제한은 파일·원장·로그·사본·백업 및 위탁 처리 사본에도 적용한다. 운영자가 독립적으로 작성한 대본·원본 영상 자체는 API 취득자료와 구분하되, 그 안에 API 자료가 포함된 경우 해당 부분에는 본 방침을 적용한다.

제4조 제공 및 처리 지원 서비스

운영자는 위 정보를 판매하거나 광고·데이터 중개 등 제3자의 독립적인 이용 목적으로 제공하지 않는다. 승인된 게시 작업에 따라 YouTube에 전송되는 자료와 공개로 지정한 영상·댓글은 해당 공개 설정에 따라 처리된다.

운영 업무 수행에는 Google/YouTube, 운영자 관리 장치 및 OpenClaw 환경을 이용한다. 승인·보고 과정에 Telegram 및 아래 AI 서비스가 관여할 수 있으므로 “외부 서비스 전송이 전혀 없다”는 의미로 해석하지 않는다. 각 서비스에는 승인된 업무에 필요한 최소 자료만 제공하며, OAuth 토큰 및 비밀번호를 보고·시연·모델 입력에 포함하지 않는다.

처리 지원 서비스 및 국외 이전

다음 표는 이용 서비스의 처리 항목·목적과 공급자 공식 정책에 따른 처리 국가·보유 기준을 정한다. 서비스 및 계정에 적용되는 지역제어·삭제·보유 설정에 따라 해당 기준을 적용한다. 클라이언트의 API 취득자료에는 제3조의 보유·삭제 의무가 적용된다.

서비스처리 국가처리 항목처리 목적보유기간
Google / YouTube — 채널 API·OAuth 플랫폼미국 등 Google 데이터센터 소재국승인된 영상·메타데이터·댓글, OAuth 인증 정보, API 요청·기술정보. 분석 지표는 API를 통하여 수신승인된 게시·채널 관리, 인증, 결과 확인 및 분석업로드 자료는 이용자가 삭제할 때까지, 일부 계정정보는 계정 삭제 시까지 보유한다. 기타 자료는 서비스별 자동삭제 기준을 적용하며, 보안·법적 의무 등 정당한 목적에 필요한 자료는 해당 목적에 필요한 기간 보유한다.
GitHub / GitHub Pages — 공개 웹페이지 호스팅미국, 이용자 소재 지역 및 GitHub·계열사·재수탁자가 운영하는 국가공개 페이지 파일과 기재된 운영자·연락처 정보, 접속 IP·요청시각 등 기술정보. 비공개 채널 원자료는 게시 대상에서 제외정책 및 서비스 안내 페이지 제공·보안공개 파일은 운영자가 게시를 유지하는 동안 보유한다. 공급자의 개인정보는 계정 활성 기간 및 계약 이행·법적 의무·분쟁 해결·약정 집행에 필요한 기간 보유한다.
Cloudflare — DNS 관리주요 저장 지역인 미국·유럽경제지역 및 Cloudflare 그룹 운영 국가DNS 설정, 계정·연락 정보, DNS 요청 관련 기술정보도메인 이름 해석 및 DNS 운영·보안서비스 제공 등 수집 목적 또는 법적 의무 이행에 필요한 기간 보유한다. 활성 계정의 연락처는 계정 운영 기간 보유하며, 보유기간 종료 후 삭제·파기하거나 기술상 삭제가 불가능한 경우 추가 이용을 제한한다.
Telegram — 운영 승인·보고 메시지Telegram의 전 세계 분산 데이터센터 소재국. 영국·유럽경제지역에서 가입한 이용자의 데이터는 네덜란드메시지·첨부, 발신 표시정보·메시지 식별자, 보고에 포함된 최소 채널 지표·검증 자료내부 승인·보고 및 운영자 통신클라우드 대화는 서비스 제공 의무의 이행에 필요한 기간 보유하며 메시지·계정 삭제 기능과 자동삭제 설정이 적용된다. 수집된 보안 메타데이터의 보유기간은 최대 12개월이다.
OpenAI — 구독·OAuth 운영 보조 및 직접 API 대본 생성미국 및 OpenAI 계열사·협력사·서비스 제공자의 처리 국가. 지역제어가 적용되는 경우 해당 서비스·프로젝트의 설정 지역업무 지시·선별 문서·대본, 보고 맥락의 최소 채널 지표·검증 자료 및 생성 결과운영 보조, 문서·대본 작성 및 검토직접 API의 남용 모니터링 로그는 기본 최대 30일이며 법적 의무·위해 방지에 필요한 연장 예외가 있다. 기능별 저장 자료에는 별도 보유기간이 적용된다. 구독·OAuth 경로는 해당 ChatGPT 서비스·워크스페이스의 보유 설정을 적용하며 서비스 제공·보안·법적 의무에 필요한 기간 보유한다.
Anthropic / Claude — 운영자가 직접 전달하는 검토미국 및 Anthropic·계열사·처리업체의 처리 국가운영자가 별도로 전달한 정책·대본 등 검토 자료운영자의 문서·대본 검토서비스 제공 등 처리 목적에 합리적으로 필요한 기간 보유한다. 이용자가 대화를 삭제하면 기록에서 즉시 제거되고 통상 30일 이내 백엔드에서 삭제된다. 적용 상품의 데이터 이용 설정 및 법령·안전·정책 집행상 보유 예외가 적용된다.
ElevenLabs — 음성 제작미국(저장), 미국·네덜란드·싱가포르(호스팅·서버)승인된 발화 대본·음성 설정·합성 결과 및 호출 기술정보콘텐츠 음성 합성처리 목적에 필요한 기간 보유하며 필요성이 종료되면 삭제하거나 개인을 식별할 수 없는 형태로 보관한다. 법률이 장기 보유를 요구하거나 허용하는 경우 해당 기간 보유한다.
fal.ai — 시각 자료 제작미국 및 fal·서비스 제공자의 서버 소재국제작 프롬프트·필요한 참조 이미지·생성 결과 및 호출 기술정보콘텐츠 이미지·영상 자료 제작계정 관련 개인정보는 계정 활성 기간 보유하고, 계정 폐쇄 후 30일 이내 또는 2년 비활성 후 삭제한다. 기타 개인정보는 최초 수집 목적 및 공급자 정책에 명시된 업무 목적에 필요한 기간 보유한다.

자료는 해당 서비스 이용 또는 승인된 작업 실행 시 네트워크로 전송된다. 이용자는 제5조의 연락처로 이전에 관한 문의 및 거부·철회 요청을 할 수 있다. 거부·철회하는 경우 해당 서비스에 의존하는 기능의 제공이 제한될 수 있다.

정책 웹페이지는 GitHub Pages에 게시할 예정이며 DNS에는 Cloudflare를 이용한다. 이들 서비스는 웹 요청에 관한 기술정보를 처리할 수 있다. 클라이언트가 직접 광고 쿠키를 설치하거나 제3자 광고를 제공하는 것은 본 방침의 운영 범위에 포함하지 않는다. Google 인증 화면의 쿠키 등은 Google의 정책에 따른다.

제5조 열람·삭제 및 권한 철회

이용자는 admin@studiopoly.ai로 대상 채널과 요청 범위를 기재하여 열람·정정·삭제·처리정지 또는 동의 철회를 요청할 수 있다. 비밀번호나 토큰을 보내서는 안 된다. 운영자는 요청자의 권한을 필요한 최소 범위에서 확인한다.

또한 Google 계정 권한 페이지 또는 서드 파티 연결 관리에서 해당 클라이언트를 선택하여 접근 권한을 삭제할 수 있다. 경로는 Google 계정 → 서드 파티 앱 및 서비스와의 연결 → 해당 연결 → 접근 권한 삭제이다. Google에서 권한을 철회하는 것과 로컬 보유자료를 삭제하는 것은 별도 절차이며, 철회 이후에도 운영자는 제3조의 삭제 의무를 이행한다. 로컬 자료 삭제는 YouTube에 게시된 영상·댓글의 삭제를 의미하지 않는다.

제6조 안전조치 및 변경

운영자는 접근 권한 제한, 비밀정보 분리 보관, 로그·시연 자료의 비밀정보 제거 및 데이터 최소화를 적용한다. 목적·항목·제공 범위가 실질적으로 변경되는 경우 변경 내용을 고지하고 필요한 동의를 다시 받는다. 개인정보 보호책임자는 신정현이며, 개인정보 문의 및 불만의 접수처는 admin@studiopoly.ai이다.
